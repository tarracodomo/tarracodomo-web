Nuestra historia

De un proyecto casero a un servicio profesional.

Tarraco Domo nace en Tarragona de una afición: montar en casa nuestros propios sensores, cámaras y automatismos. Empezamos con una estación meteorológica con una placa ESP8266, un sensor de temperatura y una pantalla OLED, y con unas cámaras ESP32-CAM integradas en Home Assistant. Lo que comenzó como un experimento nos enseñó que la domótica no tiene por qué ser cara, cerrada ni complicada.

El nombre une dos ideas. Tarraco es el nombre romano de Tarragona, la ciudad donde vivimos y trabajamos. Domo viene de domótica: la tecnología que hace una casa o un negocio más cómodo, seguro y eficiente.

Creamos esta empresa para ofrecer a nuestros vecinos y a pequeños negocios lo que aprendimos montando estos sistemas: soluciones sencillas, abiertas y que se pueden mantener y ampliar con el tiempo, sin depender de aplicaciones cerradas ni suscripciones obligatorias.

Tecnología con la que trabajamos

Componentes fiables y abiertos. Las ilustraciones son orientativas; los modelos exactos dependen de cada proyecto.

Sensores DHT11 y DHT22

Temperatura y humedad. El DHT11 es básico (±2 °C, humedad 20–80 %), el DHT22 es más preciso (±0,5 °C, humedad 0–100 %).

Sensores de movimiento PIR

Detectan presencia por infrarrojos. Sirven para alarmas, luces automáticas y para activar cámaras solo cuando hace falta.

Placas Wemos D1 con WiFi

Placas con formato tipo Arduino y WiFi integrado, cómodas para prototipos, relés y controles de la casa.

ESP32-CAM

Cámara con WiFi para vídeo, imágenes fijas y vigilancia doméstica básica integrada en Home Assistant.

ESP32-C6

Placa moderna con WiFi 6, Bluetooth 5 y radio 802.15.4 para Thread y Zigbee, pensada para dispositivos compatibles con Matter.

Pantalla OLED 0,92"

Pantalla pequeña de bajo consumo para mostrar temperatura, humedad, estado de red o alertas.

Pantalla táctil 3,5"

Panel táctil de color para mandos de pared, paneles de control y visualización de datos en tiempo real.

Módulos de relé

Permiten encender y apagar luces, enchufes y otros aparatos desde una placa o desde Home Assistant. En instalaciones a 230 V se trabaja cumpliendo la normativa.

Servomotores

Motores de giro preciso para abrir, cerrar u orientar pequeños mecanismos, cámaras y soportes con control remoto.

Placas Arduino

La placa más conocida para aprender y prototipar. Se programa con Arduino IDE y es ideal para sensores, relés y servomotores.

Raspberry Pi

Mini ordenador completo, muy usado como servidor de Home Assistant y para paneles, cámaras y monitorización.

Orange Pi y Banana Pi

Alternativas de ordenadores monoplaca. Las elegimos según el proyecto, el rendimiento necesario y la compatibilidad del software.

Bajo consumo

Los microcontroladores consumen muy poco: pueden estar funcionando las 24 horas con un gasto eléctrico mínimo y, según el montaje, alimentarse con pilas, baterías o energía solar.

Programación y código abierto

Cada proyecto se programa a medida, y el resultado es código que se puede ver, entender y mantener.

Home Assistant

Se configura con YAML y plantillas Jinja2 para crear automatizaciones, escenas y paneles. El propio Home Assistant está desarrollado en Python.

Arduino IDE

Programamos las placas en C/C++ mediante sketches (los programas de Arduino) para sensores, relés, servomotores y pantallas.

ESPHome

En las placas ESP definimos el hardware en YAML. ESPHome genera y compila el firmware en C++ y lo integra directamente con Home Assistant.

Las ventajas del código abierto

  • Sin cuotas obligatorias ni dependencia de un solo fabricante
  • Código visible, que se puede revisar y entender
  • Funcionamiento en tu red local, con más control sobre tus datos

  • Fácil de ampliar y mantener en el futuro
