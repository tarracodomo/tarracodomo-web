LILYGO T-Deck Plus

Terminal portátil con teclado y pantalla para experimentar con mensajería LoRa.

Características generales

FormatoTerminal portátil con teclado y pantalla
ProcesadorESP32-S3, según la documentación del fabricante para esta familia
RadioLoRa; la frecuencia concreta depende de la variante
ConexionesUSB-C, WiFi y Bluetooth según configuración/modelo
SoftwareFirmware compatible según modelo y soporte del proyecto

Frecuencia y compatibilidad

La imagen del repositorio identifica un modelo de 915 MHz. Esa variante no debe confundirse con la versión europea: para operar en España se necesita un equipo para la banda y región autorizadas, normalmente 868 MHz. Confirma la etiqueta y ficha del fabricante antes de comprar o emitir.

Aplicaciones

  • Mensajería LoRa desde un equipo con pantalla y teclado.
  • Pruebas de redes y nodos compatibles con el firmware instalado.
  • Terminal portátil cuando la versión y configuración regional sean adecuadas.

Fuentes: LILYGO y dispositivos compatibles con Meshtastic. Las prestaciones concretas varían según la versión.
